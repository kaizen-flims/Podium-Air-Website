PODIUM AIR WEBSITE

Privacy.

This website is a static presentation of Podium Air. It has no account system, analytics, advertising trackers, or cookies. It does not collect form submissions.

External services

When the page loads, it may request public release information from GitHub to keep the download link current. Choosing Download takes you to the signed APK hosted by GitHub. GitHub processes those requests under its own privacy terms. The page has a built-in link to the last verified stable release if the API cannot be reached.

About the Android app

The app has its own connections and permissions for music and related features. Review the source code and documentation for technical details. This page describes the website only and does not claim to be a complete app privacy policy.
